# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/ChenezDigital/gg/security/advisories/new) rather than in a public issue, or email [dev@chenez.com](mailto:dev@chenez.com). Include the affected version, your platform and steps to reproduce. You should receive a reply within a week.

## Verifying releases

Every release archive has a `.sha256` checksum and a signed build-provenance attestation. See [docs/installation.md](docs/installation.md#verifying-a-download).
